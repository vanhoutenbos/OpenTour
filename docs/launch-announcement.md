# Launch Announcement

## OpenTour v1.0 — Tee Off!

Na maanden van ontwikkeling is OpenTour klaar voor de eerste flight. OpenTour is een open-source toernooimanagement platform voor golfclubs.

### Features
- 🏌️ Toernooien aanmaken en beheren
- 📱 Offline score invoer met automatische sync
- 🏆 Live leaderboard
- 🔄 Laddercompetitie met uitdagingen
- 📊 Multi-device ondersteuning

### Getting Started
```bash
git clone https://github.com/vanhoutenbos/OpenTour.git
cd OpenTour
npm install
npm run dev
```
